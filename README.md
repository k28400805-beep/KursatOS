# 🖥️ KürşatOS

> **Sıradan bir web sitesi değil. Keşfet, oyna, kurcala.**

KürşatOS, tarayıcı üzerinde çalışan interaktif ve eğlenceli bir sanal işletim sistemi projesidir.

Masaüstündeki uygulamaları açabilir, mini oyunlar oynayabilir, Kuzeyyaka Krallığı'nı geliştirebilir, gizemleri çözebilir ve gizli terminal komutlarını keşfedebilirsin.

## ✨ Özellikler

* 🖥️ Modern sanal masaüstü
* 🎮 Mini oyunlar
* 🧪 Eğlenceli testler
* 🏰 Kuzeyyaka Krallığı
* 🕵️ Gizemli dosyalar ve şifreler
* 🌐 Rastgele ve garip bilgiler
* ⌨️ İnteraktif terminal
* 📁 Gizli dosyalar
* 🏆 Başarım sistemi
* ⭐ XP ve seviye sistemi
* 💾 `localStorage` ile kayıt sistemi
* 📱 Mobil cihaz desteği
* ✨ Modern animasyonlar ve cam efektleri
* 🔐 Gizli komutlar ve easter egg'ler

## 🎮 Mini Oyunlar

KürşatOS içerisinde farklı mini oyunlar bulunur:

* 🖱️ Tıklama Yarışı
* 🎯 Refleks Testi
* 🔢 Sayı Tahmini

Oyun oynadıkça XP kazanabilir ve seviyeni yükseltebilirsin.

## 🏰 Kuzeyyaka Krallığı

Kendi krallığını yönet!

Toplayabileceğin kaynaklar:

* 🪙 Altın
* 🪵 Odun
* 🛡️ Asker

Kaynaklarını kullanarak ordunu büyütebilir ve kaleni geliştirebilirsin.

## 🕵️ Gizem Dosyaları

KürşatOS içerisinde bazı gizli dosyalar ve görevler bulunur.

İpuçlarını takip et, şifreleri çöz ve gizli başarımları aç.

## ⌨️ Terminal

Terminali açarak sistem komutlarını deneyebilirsin.

```text

clear
about

whoami
secret
matrix
```

Bazı komutlar gizli özellikleri ortaya çıkarabilir. 👀

Hepsini açmaya çalış!

## 🛠️ Kullanılan Teknolojiler

## 🌐 GitHub Pages

Projeyi GitHub Pages ile ücretsiz olarak yayınlayabilirsin.

Repository ayarlarından:

```text

→ Pages
→ Deploy from branch
→ main
→ / (root)
→ Save
```

seçeneklerini kullan.

Birkaç dakika içerisinde KürşatOS internette çalışmaya başlayacaktır. 🚀
